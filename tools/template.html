Le projet RIVE (milieux humides MELCCFP + unités d’analyse) est poussé automatiquement dans GeoLibre. Zoomer sur la région (niveau ≥ 10) — le service masque les milieux humides au-delà du 1:600 000. Chargement manuel si besoin : Add Data → ArcGIS, coller https://geo.environnement.gouv.qc.ca/donnees/rest/services/Biodiversite/MH_potentiels/MapServer (ou le WMS https://geo.environnement.gouv.qc.ca/donnees/services/Biodiversite/MH_potentiels/MapServer/WMSServer).
